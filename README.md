# 🎯 云原神抽卡链接快取助手 (V13.2)

> 专为 `ys.mihoyo.com/cloud` 云原神Web端玩家设计。  
> 告别手动抓包，一键获取抽卡记录链接，方便导入第三方抽卡分析工具。

## ✨ 核心功能
*   **一键抓取**：点击右下角悬浮按钮，自动定位并提取含 `authkey` 的抽卡记录链接。
*   **原位读秒**：点击后，页面正中央会浮现实时倒计时（8秒），无需通过弹窗骚扰，等待过程一目了然。
*   **防拦截展示**：抓取成功后，直接在游戏画面中央弹出悬浮大文本框。支持**鼠标框选复制** 和 **手机端长按复制**，完美避开手机浏览器拦截新弹窗的限制。
*   **不死守卫**：即使云原神网页疯狂重绘 DOM，右下角的按钮也能在 1 秒内“自动复活”，永不消失。

## 📱 兼容性说明
*   **PC 端**：完美支持 Chrome、Edge、Firefox 等主流浏览器配合 Tampermonkey 使用。
*   **移动端**：安卓建议使用 **Kiwi Browser** 或 **Edge**；苹果 iOS 建议使用 **Alook** 等支持油猴的浏览器。在移动端抓取成功后，请直接在屏幕中央弹出的文本框中长按复制即可。

## 🚀 使用步骤（非常重要！）
1. **登录**：在浏览器打开 `ys.mihoyo.com/cloud` 并扫码登录云原神。
2. **开启记录**：**进入游戏画面后，务必先【手动】点击打开一次游戏内的【抽卡记录】窗口**。（这是获取链接的前提条件，不打开则无法抓取）。
3. **一键抓取**：点击网页右下角的橙色悬浮按钮 **【📋 抓取链接】**。
4. **等待读秒**：屏幕正中央会弹出 8 秒倒计时。请耐心等待。
5. **复制链接**：倒计时结束后，画面中央会弹出包含超长链接的结果框。**手机用户请直接长按链接复制，电脑用户可用鼠标框选按 Ctrl+C 复制。**

## ⚠️ 安全警告
**本工具抓取的链接内包含您个人的 `authkey`（抽卡数据授权码）。** 此凭证仅限您自己用于导入第三方分析工具。**请绝对不要将此链接分享给任何人（不要发到 QQ 群、贴吧或微信）**，否则他人可直接拉取您的抽卡历史数据。
